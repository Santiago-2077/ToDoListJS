# To-do List JS

Ejercicio pequeño de JavaScript: una lista de tareas simple con HTML, CSS y JS vanilla.

## Funciones

- Agregar tareas desde un campo de texto
- Eliminar tareas con un botón

## Uso

Abrir `index.html` en el navegador. No necesita instalación.

## Estructura

```
index.html      # Página principal
css/style.css   # Estilos
js/script.js    # Lógica de la lista
```
